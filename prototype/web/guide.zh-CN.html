01

开始你的下午

先选哪个入口？

已有进度就按「继续游戏」；「新游戏」先设置人物模板，再勾选建立新存档。原存档会封存，可从人物工坊恢复。「人物工坊」可以直接编辑男主或十位共居角色。

第一次试玩

离线示范不需要聊天 API 或 SD；它使用固定台词和本机日程。真实 AI 对话需要已配置的模型服务；SD 出图另需正在执行的本机 SD。画面上的离线标示会说明目前模式。

保存与恢复

游戏有自动进度，也可按「存档」留下手动版本。读档不会让已使用的 API 额度回退。新游戏会保留原存档；恢复后使用原来的人物与世界进度。

02

一次完成你的人物

最短操作：名字＋prompt＋保存

在左侧选男主或共居角色，输入自订名字与「角色 prompt」，按「保存并完成这位人物」。目前人物的设置立即保存；立绘差分、四方向行走图和一张 CG 会排入同一个 SD 伫列，完成后自动套用，不需要逐页保存或逐张套用。

一份 prompt 怎麽写？

用固定的外观特徵，例如 adult woman, long black hair, brown eyes, round glasses, casual long-sleeved clothes。场景与动作放在「生成细节与 CG 情境」，避免把咖啡厅背景写进所有行走图。年龄与性别由上方人物栏位指定；人物皆需成年。

LoRA 是可选的

可直接使用底模与 prompt，也可从选单选本机角色 LoRA。支援 <lora:档名:0.8> 形式的标签：依本机唯一同名资源解析，第一个作为角色 LoRA、第二个作为服装 LoRA，不会猜另一个模型。找不到、重名或架构不相容时显示原因。触发词依模型自己的要求填写。

原来的人物备援功能都在

同一页向下可调脸型、眼睛、肤色、身高、身形、八种发型、发色和起始便服配色；可设置个性、语气、目标、可选背景，以及 AI 草拟与人物卡。勾选外观细节后，这些控制也进入 SD 描述并更新原生像素备援；未勾选时由角色 prompt 主导。

名字与背景

男主与每位共居角色都能改名字，最多32字，名字需不同。名字会显示在人物名单、对话、邀约及 SD／TTS 选单；固定人物 ID 和过去记忆不变。背景只属於该人物，不能制造不存在的收入、交往或过去事件。

人物卡与 AI 草拟

AI 草拟是可选的手动操作，结果先放进同一个编辑器；正式模式会使用既有模型与用量上限，离线模式给明示范例。人物卡可汇入／汇出设置 JSON，含外观与背景，不包含金钥、世界记忆、钱包、模型权重或图片。

03

看进度、重试与替换

完整进度

左侧显示立绘差分与行走图、CG 的阶段及是否已套用。GPU 忙时会等候伫列；SD 未连线、底模未选或模板缺少必要绑定时，人物仍会保存，素材阶段显示原因，修好后按「重试未完成项目」。

自动套用的范围

套用前核对人物、已保存设置、LoRA 配方与实际穿着。生成期间改了人物或换衣服，旧任务不会覆盖新角色；旧文件保留。单改名字且美术配方没有变化，可重用完成素材，避免重做。

想选另一张？

打开「素材成果」，点缩图看立绘、表情、行走表或 CG。可选其他表情或历史素材；这个入口也提供单独重做。单独重做的任务完成后由你选用。

停止与恢复

停止这次生成只停止该人物的这次任务，不中断其他人的 SD 工作。恢复原生／汇入美术保留已生成文件。新的保存会取代旧的自动套用计画；部分失败可保留已完成的素材。

04

移动、聊天与公共场所

怎麽走与互动？

WASD 或方向键移动，点地面会寻路；点场所按钮会安排实际步行路线，走到门口即可进屋。靠近人物或物件按 E 互动。角色不在视野内时，不会把她的私有活动当成玩家已知事实。

怎麽聊天？

走近人物，按 E，再在对话框输入。对话使用目前设置的模型；离线示范是本机台词，不是 LLM 回覆。角色有各自的语气、目标、需要与记忆，可能工作、散步、拒绝邀约。

可以去哪里？

图书馆阅读并连到原始线上来源；咖啡厅购买饮品；动物园观察动物；美术馆看展；电影院看公开免费电影；餐厅吃饭；公园散步休息；市集交易；衣服店买衣服；游泳池游泳。到场后选可用物件或品项，费用与时长在界面显示。

外部内容怎麽理解？

场所保存来源连结、文字介绍与内容摘要，角色透过文字理解自己实际参与的活动。目录为已有资料快照，并非所有线上网站的即时库存或当期展览；原书、影片与网站仍开启各自来源。

05

共同活动、街坊与公共事件

多人邀约

按「共同活动」，填名称，选场所与共同品项，勾同伴并设置集合时间，发出邀约。每个人自行答应或拒绝、走到集合点，并支付自己的费用；邀请者与至少一位同伴实际到场才开始。

没到场会怎样？

开始时间后最多等待十分钟。缺席者没有活动内容、群聊或付款记忆；尚未开始时取消不收费。途中离开不会自动退回已购品项费用。免费散步也可以成为共同活动。

NPC 与小镇事件

「小镇活动」可看祭典、展览、脚本街坊与自主交流。AI 角色可和其他 AI 或一般 NPC 相遇；只有到场或听到内容的人取得相应记忆。可在部件工坊导入 NPC 脚本与公共活动定义。

06

背包、收入、市集与衣柜

男主的背包

展开「口袋与日常」，查看代币、需要、收入与物品数量。消耗品按「使用一份」会减少库存；创作材料用於作品。购买是否成为背包物品或直接进行活动，依品项本身的互动方式。

收入与创作

可在提供工作的位置打工，时间完成后领工资；回家使用材料创作物品，再带到市集寄售。角色也有自己的收入、库存、欲望与工作，不与玩家共用钱包。

市集买卖

到市集后，作品可寄售，设置数量与价格；成交收入归卖家。玩家可买角色的作品，也可收摊取回自己的寄售品。上架不代表立即成交。

衣柜与泳池

衣服店购买后进自己的衣柜，回可换装的房间选「换上这套」。行走图和 SD 配方读取实际穿着。泳池互动要求泳装；泳装 SD 生成仍需在进阶设置绑定对应服装 LoRA。拥有衣服不等於已穿上。

07

进阶 SD 与原生固定模板

第一次连接

在「游戏设置 → AI 与生成 → API 金钥与 SD 路径设置」选安装或加入路径、填本机网址并挂载，选底模，再按独立的测试连线按钮。找得到模型文件不代表服务已启动。之后人物工坊会使用这套已保存配置，无须每位人物重设底模。

已经在原生 SD 调好？

原生视窗中的设置不会被外层「保存生图设置」撷取。先下载用该设置生成的原始 PNG，收起 SD 视窗，在「从原生 SD 保存新模板」汇入 PNG／PNG Info／完整 API JSON，保存为固定模板，再为立绘、像素或一般 CG 指定用途并保存三种用途的选择。这是一次性的流程设置。

ADetailer、放大与后制

原生模板保留其 API 能表达的扩充参数。PNG 只能携带 SD 写入的生成参数；未写入的 ADetailer 或其他扩充值需完整 API payload。游戏会替换主 prompt、负向、种子、底模与所选人物；一键人物流程也会让 WebUI 的 ADetailer 正向提示跟随同一人物与表情，保留侦测器、遮罩、负向和其他后制参数。原生模板本身与原生 SD 视窗不改写。

ComfyUI 与不同用途

ComfyUI 使用 Export (API) 工作流或已完成纪录，绑定人物、底模、LoRA、参考图与 denoise 等栏位。包含角色 LoRA 节点的原生流程仍需选 LoRA；纯 prompt 可用游戏内建流程。立绘、像素与 CG 可各选不同模板，不要假设一张插图的构图设置就适合所有行走方向。

模板变数

内建固定模板可用 {identity}、{outfit}、{expression}、{direction}、{pose}、{scene}。人物 prompt 是身份，当下衣服是穿着，差分改表情，CG 再加入场景。立绘差分快取可复用；CG 表达一次构图。

08

语音、语言与用量

每人自己的声线

开「语音设置」，选 Windows、浏览器本机声线、Kokoro 或其他本机相容 TTS 服务，指定人物、朗读语言与声线，再保存或试听。神经 TTS 需先启动相容服务；下拉选模型不等於自动安装权重。

语音不等於翻译

TTS 语言控制声线与发音。游戏设置可选繁中、简中、日文与英文，影响界面、四语文件和新台词指引；人物名字、自订背景、旧台词、来源文章与原生 SD prompt 保留原文。

控制用量

动作、对话、记忆、SD 和 TTS 各有自己的接口；角色聊天沿用已配置的模型。SD 本机出图与本机朗读不扣聊天 API；AI 草拟与实际模型台词会使用既有上限。「用量与游戏资讯」可查看帐本，取消或读档不会重置已发生的 API 使用。

09

替换地图、美术、互动与 AI

用一句指示替换

开「部件工坊」，选部件类型和目标，输入如「名称改成午后花园」，按「依指示准备替换」。先看栏位差异与相容性，再套用。范例截图只显示预览，尚未改世界。

可以换哪些？

地图碰撞、门口、互动物件、背景和 PNG 素材、场所目录、单品、服装配方、人物、NPC 脚本、公共活动、底层规则、模型服务、自订工具与界面配色。完整 JSON 与部件包可汇入／汇出。

还原与自订工具

替换纪录保存旧值，可建立还原预览再套用。固定 ID 保留既有记忆、交易和库存。内建指示解析有明确支援范围，复杂要求可接本机替换 AI 服务；语句不是任意执行电脑程式的命令。

10

游戏设置与常见问题

画面与操作

游戏设置提供视野缩放、人物名字、小地图、减少动画与较大文字。设置不修改碰撞或人物记忆；暂停可以观察画面，但明确执行的游戏操作仍会按规则推进。

按保存没出图？

先看人物进度的原因。未选底模、SD API 离线、LoRA 家族不相容、泳装未绑定、ComfyUI 模板缺绑定，都会保留人物而阻挡生图。修正进阶设置后重试；名称重复、未成年或无效 prompt 会在保存前拒绝。

图片不是我想要的？

先修角色 prompt 或 LoRA，重新保存；改表情清单或姿势模板到进阶 SD。种子与身份参考能减少变化，无法保证绝对相同脸孔或完美动作。名字、外观与个性是不同栏位，图片不会自行替你编造人物背景。

百科画面代表什麽？

本百科截图来自独立离线测试世界。人物素材流程使用明示的模拟 SD，示例图片是已署名 LPC 素材，验证界面与自动套用，不代表新生成的 SD 品质；正式人物、模型、存档与工作流不在公开百科中。

12

补充：每位人物的底模与画风（v0.23）

在人物工坊选好人物，於角色 prompt 下方选「此角色底模」与「画风 LoRA」。底模可沿用全局设置；画风可留空。权重先依模型作者建议，触发词填入作者提供的文字，再按「保存并完成这位人物」。立绘差分、行走图与 CG 使用相同配方；不会把选择套到其他人。要取消角色底模覆写，改选「沿用全局底模」并保存。

此截图为隔离界面测试，图片是已署名 LPC 模拟成果。选单只列目前安装内可用的资源；已知架构不相容会阻挡生成。原生 ComfyUI 模板需另绑画风节点的 style_lora/style_weight，否则使用内建模板。

13

多画风、Refiner、ADetailer、Hires.fix（v0.24）

  1. 人物工坊选人物。第一个画风在上方选单；展开「多重画风 LoRA」新增其余画风，可调整权重、触发词、开关与顺序，最多八个。相同画风勿重复，改权重即可。
  2. 展开「精修与高解析」。先按「更新本机功能清单」查看已连线服务的侦测器、采样器及本机放大器。
  3. 每项功能选「沿用原生模板」「使用此人物设置」或「明确关闭」，再勾用途。Refiner 选模型与切换比例；ADetailer 新增修补顺序并选侦测器，正向可跟随人物与表情；其他原生修补参数可填 JSON。
  4. Hires.fix 选本机放大器、倍率、步数、重绘幅度、CFG、采样器。文字生图使用原生 Hires.fix；差分／CG 图生图采放大后二次重绘，ADetailer 放在最后一阶段。预设用途不含行走图，若需要可勾选。
  5. 最后只按一次「保存并完成这位人物」。全部跟同一份配方保存；生成用途分别生效，旧档与原生模板保留。

输出最多 2048px；未在本机的放大器不会自动下载。ComfyUI 的多画风需 native template 绑定 style_lora_2/style_weight_2…style_lora_8/style_weight_8；Refiner／ADetailer／Hires.fix 面板属 WebUI／Forge，ComfyUI 必须选沿用原生模板，自行在其工作流配置。

14

API 金钥与 SD 路径设置

在「游戏设置 → AI 与生成 → API 金钥与 SD 路径设置」填 xAI 金钥、选对话／行动模型并保存。Windows 可加密记住金钥，留空保留原金钥。保存立即生效，不生成台词；测试已保存的连线另有按钮。

选已侦测的 SD、开资料夹选择器或贴绝对路径。选含 webui.py 或 main.py 与 comfy 的安装资料夹，不只选模型资料夹。填实际本机网址：WebUI 常见7860，本环境reForge为7861，ComfyUI常见8188。保存挂载后选底模再测试；本机SD无需金钥，模型保持原位置。
