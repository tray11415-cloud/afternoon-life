# API 與 Stable Diffusion 設定

**繁體中文** · [简体中文](CONNECTION_SETTINGS.zh-CN.md) · [日本語](CONNECTION_SETTINGS.ja.md) · [English](CONNECTION_SETTINGS.en.md)

入口：**遊戲設定 → AI 與生成 → API 金鑰與 SD 路徑設定**。

## AI API

1. 勾選「啟用真實 AI」，貼上自己的 xAI API 金鑰。
2. 對話預設 Grok 4.3，行動預設 grok-build-0.1，可從已有價格設定的模型中選擇。
3. 勾選「記住金鑰」會以目前 Windows 使用者的 DPAPI 加密保存；取消則新輸入金鑰僅供本次執行。
4. 按「保存 API 設定」立即生效。金鑰留空會保留已有金鑰，不需重新輸入。
5. 需要時按「測試已保存的 API 連線」，只查模型清單，不生成對話；未保存的輸入不會用於測試。

目前此介面支援 xAI，服務網址固定為 https://api.x.ai/v1。其他本機模型可沿用「模型與工具接口」。保存不呼叫模型；原世界、模型用量帳本及工具路由沿用。金鑰不會回傳到表單，也不會放入存檔、人物卡或匯出設定。

## Stable Diffusion

1. 從「已偵測的 SD 安裝」選擇；若沒找到，按「選擇資料夾…」或貼上安裝資料夾的絕對路徑。
2. 選 WebUI／Forge 包含 `webui.py` 的資料夾，或 ComfyUI 包含 `main.py` 與 `comfy` 的資料夾。不要只選模型資料夾。
3. 填實際 SD API 網址，例如 WebUI `http://127.0.0.1:7860`、目前 reForge `http://127.0.0.1:7861`、ComfyUI `http://127.0.0.1:8188`。本機 SD 不需 API 金鑰。
4. 按「保存並掛載 SD」。首次新增資料夾後，可從全局底模選單選擇模型，再保存掛載。
5. SD 啟動後按「測試已保存的 SD 連線」。WebUI 需開啟 `--api`；可從「啟動 SD／LoRA 與完整生圖設定」進入原有啟動與人物生圖頁。

掛載直接讀取原位置的模型，不複製、不下載權重。保存掛載不會啟動 SD 或生圖。切換安裝時需使用該安裝的底模；人物 LoRA 與模板仍需相容。已有生成工作時會阻止切換掛載。

本次只驗證新增連線功能：10 項設定與路由檢查，以及 1 項離線啟動存檔隔離檢查；未重跑既有整套遊戲流程，未呼叫付費模型或生成圖片。
