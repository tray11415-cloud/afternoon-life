語音生成在背景處理；停止按鈕停止播放並丟棄尚未播出的內容，本機服務可能繼續完成正在生成的單句。相同模型、聲線、語速與台詞可重用音訊快取，最多 128 份／256 MB。神經 TTS 與 SD 同時使用 GPU 時可能互相占用資源。
