# API 与 Stable Diffusion 设置

[繁體中文](CONNECTION_SETTINGS.zh-TW.md) · **简体中文** · [日本語](CONNECTION_SETTINGS.ja.md) · [English](CONNECTION_SETTINGS.en.md)

入口：**游戏设置 → AI 与生成 → API 金钥与 SD 路径设置**。

## AI API

1. 勾选「启用真实 AI」，贴上自己的 xAI API 金钥。
2. 对话预设 Grok 4.3，行动预设 grok-build-0.1，可从已有价格设置的模型中选择。
3. 勾选「记住金钥」会以目前 Windows 使用者的 DPAPI 加密保存；取消则新输入金钥仅供本次执行。
4. 按「保存 API 设置」立即生效。金钥留空会保留已有金钥，不需重新输入。
5. 需要时按「测试已保存的 API 连线」，只查模型清单，不生成对话；未保存的输入不会用於测试。

目前此界面支援 xAI，服务网址固定为 https://api.x.ai/v1。其他本機模型可沿用「模型與工具接口」。保存不呼叫模型；原世界、模型用量帳本及工具路由沿用。金鑰不會回傳到表單，也不會放入存檔、人物卡或匯出設定。

## Stable Diffusion

1. 从「已侦测的 SD 安装」选择；若没找到，按「选择资料夹…」或贴上安装资料夹的绝对路径。
2. 选 WebUI／Forge 包含 `webui.py` 的资料夹，或 ComfyUI 包含 `main.py` 与 `comfy` 的资料夹。不要只选模型资料夹。
3. 填实际 SD API 网址，例如 WebUI `http://127.0.0.1:7860`、目前 reForge `http://127.0.0.1:7861`、ComfyUI `http://127.0.0.1:8188`。本机 SD 不需 API 金钥。
4. 按「保存并挂载 SD」。首次新增资料夹后，可从全局底模选单选择模型，再保存挂载。
5. SD 启动后按「测试已保存的 SD 连线」。WebUI 需开启 `--api`；可从「启动 SD／LoRA 与完整生图设置」进入原有启动与人物生图页。

挂载直接读取原位置的模型，不复制、不下载权重。保存挂载不会启动 SD 或生图。切换安装时需使用该安装的底模；人物 LoRA 与模板仍需相容。已有生成工作时会阻止切换挂载。

本次只验证新增连线功能：10 项设置与路由检查，以及 1 项离线启动存档隔离检查；未重跑既有整套游戏流程，未呼叫付费模型或生成图片。
