# APIとStable Diffusionの設定

[繁體中文](CONNECTION_SETTINGS.zh-TW.md) · [简体中文](CONNECTION_SETTINGS.zh-CN.md) · **日本語** · [English](CONNECTION_SETTINGS.en.md)

入口：**ゲーム設定 → AIと生成 → APIキー・SDパス設定**。

## AI API

1. 実AIを有効にし、自分のxAI APIキーを貼り付けます。
2. 会話はGrok 4.3、行動はgrok-build-0.1が既定です。使用量の価格が設定済みのモデルを選べます。
3. キー保存を選ぶと現在のWindowsユーザーのDPAPIで暗号化します。オフなら新しい入力キーは今回の実行中だけ使います。
4. API設定を保存すると即時反映します。キーを空欄にすれば既存キーを保持します。
5. 保存済みAPI接続のテストはモデル一覧だけを確認し、会話は生成しません。未保存の入力はテストしません。

このフォームは固定URL https://api.x.ai/v1 のxAIに対応します。他のローカルモデルはモデル／ツール接続を使います。保存はモデルを呼ばず、世界、使用量帳簿、ツール経路を保持します。保存キーはフォームに返さず、セーブ、人物カード、設定出力に含みません。

## Stable Diffusion

1. 検出済み環境から選ぶか、フォルダー選択か絶対パス入力を使います。
2. `webui.py` を含むWebUI／Forge、または `main.py` と `comfy` を含むComfyUIフォルダーを選びます。モデルフォルダーだけを選ばないでください。
3. 実際のローカルURLを指定します。WebUIは通常 `http://127.0.0.1:7860`、この環境のreForgeは `http://127.0.0.1:7861`、ComfyUIは通常 `http://127.0.0.1:8188` です。ローカルSDにAPIキーは不要です。
4. SD接続を保存します。新規フォルダーを接続した後は共通チェックポイントを選んで再保存できます。
5. SDを起動して保存済み接続をテストします。WebUIには `--api` が必要です。SD起動／LoRA／生成詳細設定から既存の起動と人物生成画面へ進めます。

接続は元の位置にあるモデルを読み、重みをコピー／ダウンロードしません。保存だけではSD起動も生成もしません。環境を変更したらその環境のベースモデルを使い、人物LoRA／テンプレートの互換性も必要です。生成が待機中または実行中なら切替を止めます。

接続更新は新しい設定／経路の十項目と、明示的デモのセーブ分離一項目を確認しました。既存ゲーム一式は再実行せず、この更新で課金モデル呼び出しや画像生成は行っていません。
